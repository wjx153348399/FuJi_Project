# 工站目录配置网页使用教程

本文档给现场人员使用，说明如何通过网页查看自动上传状态、维护监听目录、检查目录是否可用、查看上传日志。

## 1. 打开网页

在浏览器中打开管理员提供的网址，例如：

```text
http://服务器IP:8088/
```

打开后会进入 Dashboard 页面。如果看到页面无法打开，请先确认 Web 服务是否已启动。

## 2. Dashboard 页面怎么看

Dashboard 是状态首页，主要看三块内容：

1. 今日上传成功数量
2. 今日上传失败数量
3. 最近的监听或上传日志

如果自动上传正常，文件变更并上传后，最近日志里会出现上传成功记录。

如果出现红色或失败信息，先进入 Logs 页面查看具体原因。

## 3. 进入工站配置页面

点击页面上的：

```text
Station Config
```

进入工站目录配置页面。

这个页面用于维护“哪些共享盘目录需要被自动监听”。

## 4. 配置列表字段说明

配置列表中常见字段含义如下：

| 字段 | 说明 |
| --- | --- |
| flow | 后端上传接口使用的工站代码；未确认时可以留空 |
| 工站显示名称 | 给现场人员看的名称，例如 AFC、JXN、OUTER |
| 相对目录路径 | 共享盘根目录下面的目录路径 |
| 状态 | 启用表示会被监听；停用表示不会监听 |
| 目录检测 | 显示这个目录是否能访问 |

注意：

- `flow` 不要填写 AFC、JXN、OUTER 这类显示名称。
- 如果没有确认真实 flow，可以先留空。
- `工站显示名称` 可以填写 AFC、JXN、OUTER 等现场熟悉的名称。
- `相对目录路径` 不要填写完整共享盘地址，只填写共享盘根目录下面的路径。

## 5. 新增配置

点击：

```text
新增配置
```

按下面方式填写：

| 项目 | 填写方式 |
| --- | --- |
| flow | 未确认真实代码时留空；确认后填写类似 A557 的真实代码 |
| 工站显示名称 | 填写现场名称，例如 AFC、JXN、OUTER |
| 相对目录路径 | 填写共享盘根目录下面的目录 |
| 状态 | 需要监听就选择启用 |
| 排序 | 可填数字，数字越小越靠前 |
| 备注 | 可填写用途、确认人、说明 |

填写完成后点击保存。

如果页面提示目录不存在，请检查目录路径是否填写正确。

## 6. 编辑配置

在配置列表中点击某一行的：

```text
编辑
```

可以修改 flow、显示名称、目录路径、启用状态、备注。

修改后点击保存。

重要提醒：

- 修改目录路径后，正在运行的监听服务不会自动刷新。
- 修改完成后，需要重启监听服务，新的目录配置才会生效。

## 7. 启用和停用

如果某个目录需要自动监听，设置为启用。

如果某个目录暂时不需要监听，设置为停用。

停用后，该目录中的文件变化不会触发自动上传。

启用或停用后，也建议重启监听服务，让配置立即生效。

## 8. 检测目录

在配置列表中点击：

```text
检测目录
```

系统会检查该目录是否真实存在、是否可访问。

可能结果：

| 结果 | 说明 |
| --- | --- |
| 目录存在 | 配置正常 |
| 目录不存在 | 路径填写错误，或共享盘中没有这个目录 |
| 路径存在但不是目录 | 填到文件了，不是文件夹 |
| 访问失败 | 共享盘权限、网络或账号可能有问题 |

目录检测可能会比较慢，因为它需要访问共享盘。

## 9. 查看日志

点击：

```text
Logs
```

可以查看监听和上传日志。

常见状态：

| 状态 | 含义 |
| --- | --- |
| success | 上传成功 |
| failed | 上传失败 |
| skipped | 文件被跳过 |
| pending | 待处理或干跑记录 |

常见日志说明：

| 日志内容 | 说明 |
| --- | --- |
| watch_created | 监听到新增文件 |
| watch_modified | 监听到文件修改 |
| watch_renamed | 监听到文件重命名或移入 |
| upload_success | 上传成功 |
| upload_failed | 上传失败 |
| history_uploaded_skipped | 文件之前已成功上传，本次跳过 |

如果上传失败，请把失败日志里的文件名、错误信息、时间发给管理员。

## 10. 自动上传什么时候触发

自动上传不是打开网页后立即上传所有文件。

自动上传只在监听目录发生文件变化时触发，例如：

1. 新复制 Excel 文件到监听目录
2. 修改并保存 Excel 文件
3. 把 Excel 文件移动进监听目录
4. 重命名 Excel 文件

启动监听服务后，已经存在的旧文件不会自动补扫上传。

## 11. 修改配置后为什么没生效

配置页面保存后，数据库里的配置已经变了。

但是正在运行的监听服务启动时只读取一次配置。也就是说：

```text
修改配置
↓
保存成功
↓
需要重启监听服务
↓
新配置才会生效
```

如果不重启，旧的监听目录可能还在生效。

## 12. 现场常见问题

### 页面打开慢

可能原因：

- 正在读取共享盘日志
- 正在连接数据库
- 网络共享盘响应慢

稍等一会儿或刷新页面。如果长期很慢，联系管理员检查网络和共享盘。

### 配置页只显示 12 个目录

这是正常的。

页面显示的是数据库中启用或配置过的目录，不是共享盘里所有文件。

### 启动监听后只显示目录，不显示文件

这是正常的。

监听服务启动时只显示正在监听哪些目录，不会列出目录里的旧文件。

只有后续发生新增、修改、重命名等文件变化，才会出现具体文件日志。

### 文件没有上传

按顺序检查：

1. 文件是否是 `.xls` 或 `.xlsx`
2. 文件名是否以 `~$` 开头，`~$` 开头的是 Excel 临时文件，会跳过
3. 文件是否放在已启用的监听目录下
4. 监听服务是否正在运行
5. Logs 页面是否有失败或跳过记录
6. 后端上传接口是否返回失败

### flow 应该怎么填

如果没有确认真实 flow，先留空。

不要填写：

```text
AFC
AFX
JXN
LXD
OUTER
ZGL
```

这些是显示名称，不是后端确认的 flow。

真实 flow 需要由管理员或后端确认，例如类似：

```text
A557
A558
```

## 13. 管理员操作提醒

现场人员修改配置后，如果需要立即生效，管理员需要重启监听服务：

```powershell
Ctrl + C
python run_watcher.py --config config.json
```

Web 页面服务如果没有改配置文件，一般不需要重启。
